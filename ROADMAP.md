# Roadmap del Proyecto (8 Semanas)

## Fase 1: Investigación y Arquitectura (Semana 1)
- Definición de variables fisiológicas y escenarios.
- Creación de wireframes.
- Configuración de Firebase.

## Fase 2: Diseño de Modelos y Datos (Semana 2)
- Motor de simulación base.
- Esquema de base de datos finalizado.
- Componentes UI base.

## Fase 3: Backend Base (Semana 3)
- Autenticación funcionando.
- Endpoints de lectura de datos.

## Fase 4: Motor de Simulación (Semana 4)
- Lógica de evolución temporal.
- Generación de datos en tiempo real.

## Fase 5: Interfaz (Semanas 5-6)
- Dashboard conectado a datos de prueba.
- Simulador UI conectado al motor.

## Fase 6: Integración (Semana 7)
- Conexión Motor -> Backend -> Frontend.
- Pruebas de estrés.

## Fase 7: Pruebas Finales (Semana 8)
- Pruebas E2E.
- Documentación final y video demo.
