# Guía de Contribución y Git Flow

## Ramas
- `main`: Versiones estables (solo recibe merges de `develop`).
- `develop`: Rama de integración.
- `feature/nombre-tarea`: Ramas para desarrollo individual.

## Commits
Usar Conventional Commits:
- `feat:` Nueva funcionalidad
- `fix:` Corrección de errores
- `docs:` Documentación
- `chore:` Tareas de mantenimiento
