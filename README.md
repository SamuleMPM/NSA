# Plataforma de Monitorización de Salud Aeroespacial y Simulador de Misiones

**IMPORTANTE:** Este proyecto es exclusivamente de software. No se utiliza hardware. Todos los signos vitales son generados mediante simulaciones computacionales (datos sintéticos).

## Equipos
- **Equipo 1 (Investigación):** Fundamentos científicos y modelos fisiológicos.
- **Equipo 2 (Backend y Simulación):** Lógica central, base de datos y motor de simulación.
- **Equipo 3 (Frontend y UX):** Interfaz de usuario, dashboard y simulador.

## Tecnologías
- React/Next.js (Frontend)
- Node.js/Python (Backend y Simulación)
- Firebase (Auth, Firestore)
